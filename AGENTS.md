# AGENTS.md

## Coding Guidelines
* keep it simple
* clean code
    * no useless comments, prefer speaking variable & function names
    * small functions
* do not add libraries unless explicitly asked
* no docstrings for private methods

## Documentation

* There should be documentation for all public methods in the classes `Configurator.h` and `ConfiguratorCore.h`.
* Sync the documentation from the header files into the README.md into the subsection 'Configuration reference'.
